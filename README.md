# Технопаук: Побег

2D-платформер в индустриальном стиле (вдохновлено Rain World).

Ты управляешь небольшим техногенным пауком. Твоя цель — пройти уровень, собрать звёздочки и добраться до выхода, не попавшись монстру.

## Как скачать и запустить

### 1. Скачать проект

Нажми зелёную кнопку **Code** → **Download ZIP**  
или клонируй репозиторий:

```bash
git clone https://github.com/YngVarr473/tech-spider-escape.git
cd tech-spider-escape
```

### 2. Установить Python и Pygame

Нужен Python 3.8+.

Установи pygame:

```bash
pip install pygame
```

### 3. Запустить игру

```bash
python main.py
```

## Управление

| Клавиша              | Действие          |
|----------------------|-------------------|
| A / ←                | Идти влево        |
| D / →                | Идти вправо       |
| W / ↑ / Пробел       | Прыжок            |
| R                    | Рестарт           |
| Esc                  | Выход             |

## Цель игры

- Дойти до синей двери **EXIT**
- По пути собирать жёлтые звёздочки
- Не касаться монстра

## Что есть в игре

- Техногенный паук с процедурной анимацией лапок
- Монстр с патрулированием и преследованием
- Платформы (некоторые покачиваются)
- 10 звёздочек
- Победа и поражение
- Возможность сразу начать заново
